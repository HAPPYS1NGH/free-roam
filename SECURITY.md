# Security

Free Roam is a menu bar app that controls the Music app or Spotify and, if you turn on the cinematic backdrop, captures the screen behind the wheel. It updates itself with [Sparkle](https://sparkle-project.org), and only installs updates signed with the project's key. If you find a way to misuse any of those, or any other security problem, please report it privately.

## Reporting a vulnerability

Use [Report a vulnerability](https://github.com/HAPPYS1NGH/free-roam/security/advisories/new) on the Security tab. Please don't open a public issue.

Include the Free Roam version (select the app in Finder and choose File → Get Info), your macOS version and the steps to reproduce. I'll reply within a week and credit you in the release notes unless you'd rather I didn't.

## Supported versions

Only the [latest release](https://github.com/HAPPYS1NGH/free-roam/releases/latest) gets fixes.
